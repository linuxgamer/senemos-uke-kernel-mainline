# Security policy

This component is under active development and has no supported device release yet.

Report a vulnerability through [private vulnerability reporting](https://github.com/MCC45TR/senemos-uke-kernel-mainline/security/advisories/new). Include the affected source revision or build identity and a safe reproduction. Keep exploit details, credentials, device identifiers, calibration and raw personal logs out of public issues.

The [Uke Linux security policy](https://github.com/MCC45TR/uke-linux/blob/main/SECURITY.md) describes project-wide scope and coordinated disclosure. Ordinary bugs and hardware observations may be filed publicly after private data is removed.
